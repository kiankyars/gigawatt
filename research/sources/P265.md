# P265 — Hydraulic Institute — Pump System Operating Point (combined pump and system curves)

- **Url:** [Original source](https://datatool.pumps.org/pump-fundamentals/combined.html)

- **Use:** The system curve combines static head with friction losses that rise with flow; the operating point is where it crosses the pump curve. Closing a valve steepens the system curve, and changing pump speed shifts the pump curve according to the affinity laws.
