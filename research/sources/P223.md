## Claim-level notes

Reviewed 2026-09-17: documentation introduction and “Choose Console or SunkCluster CR.”

- SUNK is a managed route for running Slurm on Kubernetes.
- A declared cluster drives provisioning of compute, Slurm control services, login pods, shared storage, and access.
- Users connect over SSH and submit Slurm jobs; console and manifest workflows differ in the setup the customer performs.

## Evidence scope

SSH access does not imply an unmanaged server: it also exists in this managed product. This documentation does not describe every CoreWeave customer configuration or guarantee that all operational tasks are provider-owned.

## Teaching use

Use SUNK as the concrete counterexample to the assumption that GPU infrastructure is simply hardware plus an SSH key. Keep Slurm and Kubernetes implementation details in the compute/operations lessons; here the purpose is to identify the commercial service boundary.
